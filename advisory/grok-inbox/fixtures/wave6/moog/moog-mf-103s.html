Change Log

1.3.0

  • Performance improvements to internal DSP.
  • Improvements to software licensing.
  • Virtual CV slots can now be renamed.
  • Added small resize graphic in the bottom right corner to indicates where the resize area is.
  • Host automation parameters now look cleaner in DAWs.
  • Host automation parameters order is now more logical when viewing as a list.
  • LFO phase is now reset when render starts for more consistent render results.
  • LFO sync tracking after transport start has been tightened up.
  • Fixed MF-105S MURF LFO voltage being output when set to Off.
  • Fix for plugin window size not being remembered when closing and re-opening window.
  • Fix for flipping switches sometimes causing the UI to slightly shift.
