Latest plug-in versions and documentation

All our plug-ins operate as 30-day fully functional demos until you buy a license and authorize them.

When installing the plug-ins you will choose a licensing method: Wave Arts or iLok. If using Wave Arts, the plug will run for 30 days until you register with a serial. If using iLok you will get a popup window where you can start a trial activation or activate using an activation code. The activation code can be fetched at our registration page.

Product Registration

After purchasing a plug-in, you will receive a product serial number. Open the plug-in, select Settings->Register, and enter your serial and name and email. If you are using iLok licensing, fill out the product registration form to receive an iLok activation code.
