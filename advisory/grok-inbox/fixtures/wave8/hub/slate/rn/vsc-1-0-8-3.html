VSC 1.0.8.3 - Release Notes

QA Team
July 13, 2017 20:56
Follow

Improvements

  • Added the Device Browser
  • Added a Reset Reverb Parameters in the Configuration Menu
  • Removed the scroll wheel for switching between Devices
  • Longer Pre-Delay Time
  • Updated some Presets and Devices
  • Added snapper at 0 for Gain, EQ Gains and Width
  • Updated the User Guide
  • Added tooltips in the preset bar
  • AudioUnit SDK update
  • Windows only: Added an informative message in the installer for the IR folders hierarchy

Bugs Fixed

  • AU Validation is stuck when scanning VSC with missing IRs
  • Decay time anomaly when switching between specific presets
  • Potential crashes when inserting VerbSuite in Pro Tools 10
  • FG-16X Rooms are too much tilted to the left

Known Issues

  • Mac and Bitwig only: GUI only opens half way
  • Mac only: IRs Locate panel appears behind the plugin GUI

Nota Bene

  • The plugin is stereo only
  • No bypass is available directly in the GUI
  • Dry/Wet parameter is not saved in the Presets, just in the Snapshots and the Default Preset

Shared Framework Issues

  • Windows only: Cropped GUI when resizing the plugin in Maschine and Bitwig
  • Windows and Reaper VST3 only: Full-speed Offline Renders don't read correctly the automation
  • Pro Tools 12: Committing a track brings a Tail with Noisy Plugins
  • OS X 10.11 only: Sluggish video when GUI is open
  • FL Studio and VST3 only: Automations are not read when rendering or when GUI is closed
  • Mac and Wavelab VST2 32-bit only: GUI Disorder
  • Wavelab and Audio File Workspace only: Silence added at the end of files (1s) when rendering | Workaround: Enable “No Tail” in the rendering options.
  • WaveLab and  Audio File Workspace: Fade-out at boundary (rendering option) doesn't work
  • Triumph only: Process is missing when rendering
  • Triumph only: Crash when closing sessions
  • Triumph only: Plugins are not recalled when reloading a session
  • Digital Performer 8 and VST2 only: Plugins fail examination
  • Mac only: Launching Studio One 2 without iLok crashes the DAW
  • Sony Vegas Pro only: Settings/Parameters are not recalled
  • Vienna Ensemble Pro and AU only: Blank GUI

--

Compatibility Notes

  • Device Browser improvement: Factory and FG-BM7 units must be updated
  • Pre-delay improvement: Pre-delay automation lines must be re-adjusted
