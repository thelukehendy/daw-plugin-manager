Apple M4 Compatibility & Troubleshooting

✅ Slate Digital plugins are fully compatible with Apple M4 processors. If you're experiencing licensing errors on an M4 Mac, updating to the latest plugin versions will resolve the issue.

Download the latest versions from the Installers page or through Complete Access Hub (formerly known as Slate Digital Connect).

⚙️ Common M4 Licensing Errors

If you see any of the following errors on an M4 Mac, a plugin update is all that's needed:

  • "Internal Conductor Error 1"
  • "Internal Conductor Error 101"
  • "iLok Server Error: Object Not Found"

These errors were caused by a CPU timing conflict within iLok's licensing system on M4 processors. PACE (iLok) identified the root cause and released a fix, which has been integrated into all current Slate Digital plugin versions.

🛠️ How to Update

  • Complete Access Hub: Open the app and install the latest plugin updates
  • Installers Page: Download updated versions directly from this link

🔄 Do I need to update iLok License Manager?

No — updating iLok License Manager is not required. That said, keeping it current is always a good idea for general compatibility.
