New Features in FL Studio 26

FL Studio owners enjoy LIFETIME FREE UPDATES, so always check for the latest release here online. For the complete log (including bug-fixes) please check the WhatsNew Change Log. You can also view the FL Studio YouTube playlist.

FL Studio 2026 (7 July 2026)

WHAT'S NEW?

  • FL Studio:
    • Backup projects to FL Cloud - All customers get access to FL Cloud project backups (Free 500 MB, Plus 5 GB & Pro 1 TB). Use File > Save and backup to FL Cloud or enable the option under Project settings > Project > 'Backup to FL Cloud storage' to auto-save to FL Cloud on each save. Saved projects appear in the Browser under 'FL Cloud > Project backups'. You can (Right-Click) any project in the Browser to 'Download' or 'Delete' it.
    • Tools Menu - Audio Logger tool. Similar to the MIDI Logger, FL Studio is now always recording audio from the Master Mixer Track.
    • Audio Settings (macOS) - Now includes separate Audio Input & Output device selectors.
    • MIDI Recording - FL Studio should now more accurately record incoming MIDI events (much less jitter) and also when the Tempo changes during playback.
    • Help Menu - Added some guided tutorials (Loop starter tutorial & Step sequencer tutorial). Removed 'Product information'.
    • Tools Menu - Added 'Chord Progression tool' and 'Remix a song'.
    • Options Menu - Added 'Account Settings' option.
    • Account Tab - Moved 'Show license information in the hint panel' option to the Account Tab in the Settings window
    • Projects - When 'License Plate' is selected in Accounts Settings, the License Plate rather than User Name will be saved in project files.
    • Welcome Window - New 'Remix a song' option that loads and stem-separates a track in the Playlist with a single click.
    • Rename pop-ups - Are now slightly wider. Only slightly so you still have something to complain about.
    • CPU Performance (Windows) - Changed the way the Windows Performance Plan is requested to avoid CPU throttling.
    • Communications Panel - Renamed the Communications Panel, 'Downloads' Tab to 'Transfers'.
    • Account - New 'Account' Tab in the Settings window. Access Image Line account and FL Cloud information.
    • Toolbar Panel - Chord Detection panel. Detects chords from MIDI, Typing keyboard to piano and note selections in the Piano roll. NOTE: If it's not visible edit the Toolbar to add this new tool. The maximum number of detected notes is limited to 10.
    • Popup messages & options - Changed 'Don't show this in the future' options to a more effective 'Remember my choice'. We remember!
    • Improved envelope preset loading - FL Studio uses .fnv format for multiple enveloper editors in the application, some are incompatible. Now .fnv files now show a clear message instead of failing silently, and drag-and-drop behaves consistently.
    • Plugin Manager:
      • Improved speed – Large plugin lists now load faster for a smoother browsing experience.
      • Rescan all plugins – Added a warning when 'Rescan all' is enabled to prevent accidental long scans.
      • Waves plugins – Added an option to control whether Waves plugins are always re-verified.
    • Audio & Instrument Tracks - FL Studio will now indicate which associated Channels will be deleted when deleting an Audio/Instrument mixer track.
    • Apple Silicon Performance - macOS now uses Audio Workgroups API to make sure audio threads work toward a common deadline. This reduces the risk of underruns when audio CPU usage suddenly increases.
    • Speechsynth - Shows an message when trying to load a speech synth preset on macOS as it's not compatible.
    • Plugin Management - Audio Unit (macOS) plugins are now at the end of the 'More' plugins list by default to encourage VST usage for compatibility.
    • Plugin & Project Pickers - The search text can now be longer than 40 characters.
  • New Plugins:
    • Transmitter (All Plugins Edition) - Splits the input signal into Transient and Sustained audio streams for independent dynamics, spectral shaping and effects processing. The Transient envelope can also act as an internal controller.
    • FL Studio Mobile & Rack - Get access to all FL Studio Mobile plugins. Most recently added ...
      • SoundFont Player - Loads SF2 SoundFont banks.
      • Note Arpeggiator - Turn incoming notes into rhythmic, repeating, and re-pitched patterns.
  • Plugin Updates:
    • FLEX - FLEX has been rebuilt from the ground up with a new synthesis engine offering up to 50% lower CPU use, when used with 2nd generation Packs, alongside a redesigned UI with simplified controls and improved search at both the pack and preset level.
    • Gross Beat - New 'Trigger slots from MIDI notes' option to turn MIDI notes off so they don't trigger slots when Gross beat is focused. Improved processing during small tempo changes (the delay line no longer resets).
    • Patcher > Menu > Show info inside modules - Displays the View data inside the Module UI. Otherwise, when deselected it's shown above the Module UI.
    • FPC - You can now drop multiple samples on an FPC Pad to create layers.
    • Video Player - Show the last frame when the playback position is beyond the end so the display is not black.
    • Patcher - The window can now be smaller when a Surface Tab is selected, for improved UI design.
    • Plugin Wrapper Menu - Added 'Replace' to select from the Plugin Database.
    • MIDI Out - Added a 'Send program change' option. This can help with certain hardware synthesizers that don't have internal controls to ignore these messages.
    • Edison - Scripts are no longer re-applied on accept if a preview already exists.
    • Luxeverb - Added a Pitch Feedforward mode and 100 new presets.
    • DirectWave - Added (Shift+Click) support to select multiple Zones in the list. Zones are activated when selected with up/down arrow keys.
    • Emphasis - Disabled the Low Latency option when Instant Recovery is enabled.
  • Piano roll:
    • User key labels – You can (Right-Click) any Key and select Rename to enter your own text label in all View modes. Select Key labels to manage Note label presets or choose Keyboard Views.
    • Chord Stamp Tool – Added top-down and bottom-up modes with voice-leading. Top-down lets your melody lead the harmony, the note you click becomes part of the chord that's built underneath it. Bottom-up is more harmony-driven where FL Studio chooses a chord for you based on where you click. Great for quick ideas and 'inspire me' workflows.
    • Chord Progression Tool - When Typing to piano keyboard is selected, you can preview Chords starting from C5. When editing, Chord nudge - Allows to you swap chords by clicking and dragging.
    • Piano roll - Tools icon (Right-Click) now opens the Chord Progression Tool instead of Riff Machine now moved to (Middle-Click).
    • File > Open score - Shows both .mid files in addition to .fsc files as Supported score files is selected in the Operating System browser. Because, when you want a score you don't really care about the format!
    • Note editing - Stretching selections in the Piano roll now snap by default, use (Alt) for unsnapped stretching. This harmonizes the behavior with other snapped vs unsnapped editing.
    • Piano roll menu – Exporting to 'MIDI' or 'Score sheet' now defaults to the Project's Data Folder when set. Otherwise '... Documents/Image-Line/FL Studio/Presets/Scores' will be used.
  • Channel Rack
    • Loop Starter - Added a popup menu arrow button next to the Loop Starter dice controls for better menu visibility. Files downloaded by Loop Starter are now deleted automatically if they're not used to avoid the pop-up. FL Cloud status badge is now visible when using Loop Starter - allowing easier discovery of an extended loop library available to subscribers. Expanded loop library for FL Cloud Plus and FL Cloud Pro subscribers. Added 'Show more from this pack' on the track menu to show the pack from which the samples came. Renamed the 'Change project tempo' to 'Auto tempo'.
    • Stepsequencer - Changed the default value of ‘Use both mouse buttons in step sequencer’ off.
    • Channel Button - 'Replace' option to choose from the favorites list.
    • Channel Rack Menu – Sort by > Type. Sorts Channels by their type: e.g Sampler Channels, Instruments/Generators, Automation Clips, Audio Clips.
  • Playlist:
    • Audio Clip Gain Controls (Right-Click) - Added Normalize selected Audio Clips with the option to Normalize selected Clips individually or relative to the loudest Clip in the selection. Updated option names to be clearer, Normalize selection individually, Normalize selection as a group.
    • Audio Clip Properties - Now includes Pan control and adapts to whether they apply to a single Audio Clip or multi-selection. Context dependent options allow changes to be applied in a more granular way.
    • Audio Clips - Added a new mouse cursor to distinguish Clip Resizing from Clip Stretching modes as selected from the Clip Focus panel.
    • Audio Clip Editing - When the Typing to piano option is deselected, holding 'A' temporarily switches between Resizing and Stretching Audio Clips.
    • Playlist > Edit Menu - Use 'Select tracks when samples are dropped' to select or not-select Tracks when samples are dropped.
    • Playlist Menu - Revised the order of items in the Playlist window menu.
    • Multi-selected sample dropping - No longer select all Playlist tracks when a group of samples is dropped onto the Playlist
    • Audio Clip Titlebar - Shows Pan and Pitch values if changed from the default. Improved display of Pitch and Pan values in Audio Clip Title bars.
    • Menu > Automation clips reset remote controls - Providing the option to takeover manually tweaked controls. Previously playback would need to be restarted to have the Automation Clip regain control.
    • Menu > Collapse / Expand all grouped tracks - Minimize / Expand the height of all Grouped Playlist Tracks.
    • Menu > Edit patterns in > Scroll to position - Renamed 'Adjust start time' to 'Scroll to position' switch to more clearly explain the features action.
    • Performance Mode – Added a pop-up panel when preparing for Performance Mode to select Marker Count and Spacing. Markers are used to trigger Clip Columns.
  • Mixer
    • Mixer - Reset Input and Output selectors to '(none)' on (Alt+Left-Click)
    • FX Slots - Clicking an unused Mixer Effect Slot now shows only the Plugin selection menu.
    • Menu - Renamed 'Open audio logger' in the Mixer Menu/s to 'Open audio editor and record' to disambiguate it from the global Audio Logger tool.
  • Browser:
    • Project Backups - Auto saved projects now include the save date in the file name.
    • .ZIP files - Now show the same menu as for project files including open.
    • Browser UI - Increased the default width of the Browser to show 3 packs in a row in the Sounds Tab.
    • Browser Tab (Menu) (Right-Click) - Option 'Show sample waveform' displays preview waveforms in-line.
  • Gopher
    • Gopher - Gopher can now control some features in FL Studio and plugins. NOTE: This is an experimental feature.
    • Improved Scripting support - Gopher is now able to create improved Piano roll and VFX Scripts on demand. For example, ask Gopher for create a Piano roll script to remove random notes from a score.
  • MIDI scripting:
    • Added HW_Dirty flags" for undo and redo operations.
    • Replaced the built-in MCU support with the new MCU script.
    • Added 'setPatternLength' and 'incrementPatternLength' functions.
    • Added added 'get_swing' and 'set_swing' functions to set and get swing values.

2026.1.1 Maintenance Update (13 July 2026)

Changes

  • FL Studio - Sample and plugin names are shown in the Missing Samples window.
  • FL Studio - Shows the project backup file name in the notification after a download finishes.
  • FL Studio - Now cleans up Temp folders of previous FL Studio instance/sessions.
  • FL Studio - The maximum backup count can now be set as low as 1.
  • Browser - Added 'Remember my choice' option to the message shown when deleting a file from the Browser.
  • Browser - Colors of buttons are matched to the Sample preview when in 'Samples' view layout.
  • Gross Beat - Better handling of Tempo changes.
  • Love Philter - Added undo for non-automatable controls.
  • MIDI scripting - Added optional destination index to the ClonePattern function.
  • Plugin Wrapper - Shows the keyboard focus button for less wide plugins.
